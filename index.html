Data Notes

Considerations for interpreting the assessment results.

Assessment data: The dashboard uses the MPS and learner-classification data provided for Grades 7–10.

Learner counts: Learners are represented within each grade-level and learning-area record. The same learner may therefore appear in more than one learning area. Learner counts should not be added across subjects to determine the school's total learner population.
